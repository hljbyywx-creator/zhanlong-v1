## 一、生产管线与硬约束

1. **生图通道与并发控制**
   - 脚本：`plates-src/gen.sh <id> a <style-file> [ref.png ...]`
   - 模型：本机 Magpie 网关 `codex exec -m gpt-6.1-sol -c model_reasoning_effort="high"`（`< /dev/null`，禁开 fast）
   - 并发上限：**严格 `max_workers = 2`**，逐张监控日志 `plates-src/logs/<id>-a.log`。若遇安全词拦截或空文件，立即柔化措辞并以 `FORCE=1` 重跑，直至 32/32 PNG 全部有效就绪。

2. **画风模板矩阵（`plates-src/prompts/_style*.txt`）**
   - `_style.txt`：南宋院体宣纸水墨（冷冽留白、斧劈皴、飞白、矿物淡设色）——用于人间界、承启天、三方虚空、真实之域、虹桥废墟等。
   - `_style-gold.txt`：千里江山青绿金碧山水＋宋代界画宫阙——用于太霄道境、中央道宫、符诏受领、道境万雷织茧。
   - `_style-terrace.txt`：苍莽古旧宣纸浓墨破墨＋朱砂暗赭金石质感——用于上清崩坠、四御门庭、封神斩龙台、光阴回溯。
   - `_style-eyes.txt`（本轮新增专用）：同源南宋宣纸水墨笔意，唯独放开「沧桑眉骨＋半阖古意双眸横幅极特写」，瞳心一点矿物朱砂赤芒、眼底叠染深不见底的石绿幽渊，禁绝写实高光与动漫眼型。
   - `_style-star.txt`：磁青描金宣纸水墨＋宋代石刻天文图星轨——用于中天紫微星空大殿、清净散人遗骸。
   - `_style-sp.txt`：纯白底 `#FFFFFF` 梁楷减笔写意抠图立绘——用于 `#23`–`#32` 角色与道具层。

3. **质量与合规红线**
   - **安全词规避**：全量提示词禁用血腥、尸骸、断头、自残等触发词；古战场与封神台统一转译为折戟残旗、雾中空甲、浸石朱砂暗赭矿彩锈迹、穿袍青铜朱砂篆链、星光下风化石质禅坐残影、十七足浓墨烟霭蛛影。
   - **禁露五官**：除 `#17 cu-yang-eyes` 专用眼部写意特写外，`#1`–`#16` 与 `#18`–`#32` 所有人物一律取背影、侧背影、深影轮廓或冠冕云雾遮蔽，绝不描绘五官。
   - **字幕安全带**：`#1`–`#22` 全部 `p-*` / `il-*` / `cu-*` 底图底部 `20%` 保持留白、平缓云水或静谧暗墨，不落关键视觉焦点。
   - **抠图净空与白底**：`#23`–`#32` 全部 `sp-*` 强制单主体居中、四周留足净空（头脚/肢端绝不触边裁切），外部纯平 `#FFFFFF` 零阴影零纸纹。

4. **后处理规格（`/opt/homebrew/bin/python3.11` + `Pillow`）**
   - `#1`–`#22`（`p-*`, `il-*`, `cu-*`）：居中裁切至精确 `16:9`，`LANCZOS` 缩放至 `1920x1080`，输出 RGB WebP（`quality=84, method=6`）至 `plates/<id>.webp`。
   - `#23`–`#32`（`sp-*`）：执行 `sp-cutout.py samples/<id>-a.png /tmp/<id>-cut.png 2 246` 泛洪去白底并保留边缘水墨浓度半透明，按 `alpha > 16` 包围盒外扩 `16px` 自动裁边，限制长边 `<= 1400px` 等比缩放，输出 RGBA WebP（`quality=88, method=6`）至 `plates/<id>.webp`，并校验四角零残留不透明白块。
   - 审阅拼图：输出 `plates-src/CONTACT-SHEET-SCENES.jpg`（22 张场景/特写 `4x6` 网格，`1600px` 宽）与 `plates-src/CONTACT-SHEET-SPRITES.jpg`（10 张抠图叠于 `#d8c9ab` 棋盘格，`1400px` 宽）。
